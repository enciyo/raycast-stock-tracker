# Stock Tracker

A Raycast extension to track and monitor your stock portfolio.

## Features

- Search for stocks
- View your portfolio and watchlist
- Track stock prices in real-time

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build for production
npm run build

# Lint code
npm run lint

# Fix linting issues
npm run fix-lint
```

## Commands

- **Search Stocks**: Search for stocks and add them to your watchlist
- **View Portfolio**: View your stock portfolio and watchlist
